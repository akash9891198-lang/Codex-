# Mobile Chess

A touch-friendly chess game built for mobile browsers.

## Features
- Full legal move validation using `chess.js`
- Check, checkmate, and draw detection
- Pawn promotion support
- Undo move and reset game controls
- Responsive board sized for phones

## Run locally
Open `index.html` directly, or serve the folder with a static server:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> in your browser.
